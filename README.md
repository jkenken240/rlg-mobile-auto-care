# RLG Mobile Auto Care

Responsive marketing website for RLG Mobile Auto Care, a home-service car detailing business based in Tanauan City, Batangas.

**Live website:** [mobile-auto-care.khen-guinez.chatgpt.site](https://mobile-auto-care.khen-guinez.chatgpt.site)

![RLG Mobile Auto Care home-service detailing](public/images/rlg-mobile-detailing-hero.webp)

## About the project

The website presents RLG's detailing services in a polished, mobile-first format and gives prospective customers direct ways to ask for a quotation. It combines realistic service imagery, clear starting prices, service coverage information, and Messenger and phone calls to action.

## Features

- Responsive single-page layout for desktop, tablet, and mobile
- Service packages with inclusions and starting prices
- Ceramic coating promotion and vehicle-based pricing
- Visual sections for exterior, interior, and ceramic care
- Three-step booking explanation
- Service-area and operating-hours information
- Direct Messenger, Facebook, and telephone links
- Accessible navigation, headings, labels, and image descriptions

## Technology

- TypeScript
- React 19
- Next.js 16
- Vinext and Vite
- Tailwind CSS 4 and custom CSS
- Cloudflare-compatible server output

## Run locally

The included build helpers require Linux or WSL, Node.js `22.13.0` or newer, and npm.

```bash
npm ci
npm run dev
```

Useful commands:

```bash
npm run lint
npm test
npm run build
```

## Main project files

```text
app/page.tsx          Page content and service data
app/globals.css       Responsive design and visual effects
app/layout.tsx        Metadata, fonts, and document layout
public/images/        RLG brand and service imagery
```

## Project status

This is a working portfolio and business website. Prices, operating hours, coverage, and contact information should be reconfirmed with RLG before any future production launch or major campaign.
